# Flowchart Understanding

The `flowchart` package contains utilities to run InternVL, Qwen, Comet, Prometheus and Gemini API models
mainly targeting flowchart related tasks. It also includes a Mermaid compiler, that compiles Mermaid code
into `networkx` graphs and that decompiles back to Mermaid codes. Alongside the compiler, there also exists
a visualization tool to generate flowchart images, with augmentations and other configurations.
